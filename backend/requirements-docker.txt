# 容器镜像专用依赖(2026-10-27)
#
# 与 backend/requirements.txt 的差别只有两类,原因如下:
#
# 1) 去掉 sentence-transformers —— 它在 backend/app 里零引用(embedding 走 DashScope
#    远程 API),却会把 torch 拖进镜像(linux wheel GB 级)。Docker 构建实测因此卡住。
# 2) 去掉 faster-whisper / yt-dlp —— 两者在代码里都是懒加载,且自带「未安装则降级」
#    分支(whisper_service.py 降级到云端转写;ytdlp_service._check_yt_dlp 返回 False)。
#    容器内不需要本地转写/视频下载能力。
#    若要让容器恢复这些能力:把对应两行加回本文件即可(镜像会显著变大)。
#
# 另外给 langchain / langchain-openai / langchain-community 补了上界:
# 原 requirements.txt 三者无上界,与 langgraph<0.3.0 冲突时 pip 会从 1.2.x 一路回溯到
# 0.3.x(实测约 3 分钟)。上界对齐本机实测版本(langchain 0.3.30 / openai 0.3.35 /
# community 0.3.31),让构建可复现。本文件只影响镜像,不改本机安装。
